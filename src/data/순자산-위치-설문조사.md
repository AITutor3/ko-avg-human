# 순자산 위치 설문조사 결과 이미지

## 카드용 공통 제작 기준

- 용도: 결과 카드 중앙에 들어갈 유형별 캐릭터 일러스트
- 비율: 1:1, 1024×1024 PNG
- 배경: 반드시 완전한 흰색(`#FFFFFF`). 배경 오브젝트, 테두리, 패턴, 그라데이션, 바닥선, 그림자 없음
- 스타일: 참고 이미지처럼 굵고 살짝 불규칙한 검정 외곽선, 손으로 그린 듯한 한국 웹툰 낙서풍, 단순한 둥근 인체 비율, 무표정에 가까운 능청스러운 표정, 흑백·회색 중심에 결과별 포인트색 1개
- 구도: 한 명의 전신 캐릭터와 핵심 소품을 중앙 75% 안에 크게 배치. 상하좌우에 카드 문구가 들어갈 충분한 여백 확보
- 금지: 이미지 안의 글자, 숫자, 말풍선, 캡션, 로고, 워터마크, 사실적인 3D 렌더링, 복잡한 배경

## 영앤리치 자산가 — 황금빛 1인가구

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 캐릭터 일러스트. 완전한 흰색(#FFFFFF) 배경 한가운데, 짧은 검정 코트를 단정하게 입은 젊은 인물이 한 손은 주머니에 넣고 다른 손으로 작은 금빛 동전 하나를 가볍게 튕기며 여유롭게 서 있다. 손목에는 심플한 시계, 발밑 옆에는 작고 각진 서류가방 하나만 둔다. 눈썹을 살짝 올린 담담하고 자신감 있는 표정. 굵고 살짝 삐뚤한 검정 외곽선, 손으로 그린 듯한 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리의 귀여운 전신 비율, 흑백과 짙은 회색 중심, 오직 동전과 시계에만 절제된 머스터드 골드 포인트. 중앙 75% 안에 선명한 실루엣, 카드 문구를 위한 넉넉한 흰 여백. 배경 오브젝트, 바닥선, 그림자, 그라데이션, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 3D, 점토 질감, 사실적 렌더링 금지.
```
