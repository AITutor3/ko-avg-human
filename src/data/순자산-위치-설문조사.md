# 순자산 위치 설문조사 캐릭터 이미지

## 카드용 공통 제작 기준

- 용도: 결과 카드 중앙의 작은 캐릭터 이미지
- 비율: 1:1, 1024×1024 PNG
- 배경: 투명 배경
- 구도: 캐릭터 전신이 중앙 70% 안에 들어오는 정면 구도
- 스타일: 한국 모바일 앱에 어울리는 귀여운 3D 클레이 토이 스타일
- 주의: 이미지 안에 글자, 숫자, 말풍선, 로고, 워터마크를 넣지 않는다.
