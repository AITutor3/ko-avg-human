# 이상형 희소성 설문조사 캐릭터 이미지

## 카드용 공통 제작 기준

- 1:1, 1024×1024 PNG, 투명 배경
- 귀여운 둥근 곰 마스코트의 3D 클레이 토이 스타일
- 카드 중앙에서 바로 읽히는 단순한 포즈와 소품
- 글자, 숫자, 말풍선, 로고, 워터마크 금지

## 유니콘을 찾는 사람 — 유니콘 수색꾼

```text
귀여운 둥근 갈색 곰 마스코트가 탐정 모자와 작은 분홍 망원경을 들고 희귀한 유니콘을 찾는 모습, 곰 옆에는 무지갯빛 갈기와 작은 뿔을 가진 미니 유니콘이 구름처럼 살짝 나타난다. 호기심 많고 눈이 높은 캐릭터를 유쾌하게 표현, 핫핑크·보라·하늘색·무지개 포인트, 한국 모바일 결과 카드용 고품질 3D 클레이 토이 캐릭터, 부드러운 조명, 명확한 실루엣, 정면 전신, 중앙 배치, 작은 크기에서도 망원경과 유니콘 뿔이 선명하게 보이도록, 1:1, transparent background, isolated character, no text, no numbers, no speech bubble, no logo, no watermark
```

## 현실 찰떡 러버 — 현실 사랑꾼

```text
귀여운 둥근 갈색 곰 마스코트가 서로 꼭 맞는 두 개의 하트 퍼즐 조각을 두 손으로 맞추고 있다. 머리에는 작은 벚꽃 한 송이, 편안하고 따뜻한 미소, 조건보다 마음이 잘 통하는 사랑을 표현한다. 코랄핑크·연보라·크림 색감, 한국 모바일 결과 카드용 3D 클레이 토이 캐릭터, 부드러운 조명, 단순한 형태, 정면 전신, 중앙 배치, 작은 크기에서도 하트 퍼즐이 확실히 보이도록, 1:1, transparent background, isolated character, no text, no numbers, no speech bubble, no logo, no watermark
```
