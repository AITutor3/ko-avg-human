# 이상형 희소성 설문조사 결과 이미지

## 카드용 공통 제작 기준

- 1:1, 1024×1024 PNG, 반드시 완전한 흰색(`#FFFFFF`) 배경
- 굵고 살짝 불규칙한 검정 외곽선과 담백한 한국 웹툰 낙서풍
- 둥근 머리, 짧은 팔다리, 무심한 표정의 한 명짜리 전신 인물 캐릭터
- 흑백·회색 중심에 결과별 포인트색 1개만 사용
- 캐릭터와 핵심 소품을 중앙 75% 안에 배치하고 카드 문구용 흰 여백 확보
- 글자, 숫자, 말풍선, 로고, 워터마크, 그림자, 바닥선, 풍경 배경, 3D 렌더링 금지

## 유니콘을 찾는 사람 — 유니콘 수색꾼

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 탐정풍 체크 코트와 작은 사냥모자를 쓴 인물이 한쪽 눈을 가늘게 뜨고 망원경으로 먼 곳을 살핀다. 다른 손에는 체크 표시가 전혀 없는 빈 메모장을 들고 있으며, 모자 위에는 작은 유니콘 뿔 장식 하나가 엉뚱하게 달려 있다. 아주 까다로운 대상을 끈질기게 찾는 진지하면서도 우스운 표정. 굵고 삐뚤한 검정 외곽선, 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 회색 중심, 오직 망원경과 뿔에만 보라색 포인트. 중앙 75% 안에 전신과 소품, 넉넉한 흰 여백. 실제 유니콘이나 풍경 배경, 그림자, 바닥선, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 3D 금지.
```

## 현실 찰떡 러버 — 현실 사랑꾼

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 편안한 회색 니트와 면바지를 입은 인물이 서로 꼭 맞는 두 개의 하트 퍼즐 조각을 양손으로 맞춘다. 고개를 살짝 숙여 퍼즐을 바라보며 입꼬리만 은근히 올라간 편안하고 따뜻한 표정, 힘을 뺀 자연스러운 자세. 굵고 살짝 불규칙한 검정 외곽선, 담백한 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 연회색 중심, 오직 맞물린 퍼즐 조각에만 살구빛 코랄 포인트. 중앙 75% 안의 간결한 전신 실루엣, 카드 문구용 넉넉한 흰 여백. 추가 하트 장식, 배경 요소, 그림자, 바닥선, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 3D 금지.
```
