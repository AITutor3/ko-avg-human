# 대한민국 평균 백분위 계산 기준 및 공식 근거 데이터

> 최종 검증일: 2026-09-07  
> 원칙: 공식 공표값과 서비스의 추정값을 구분한다. 공식 통계가 평균만 제공하면 이를 중앙값으로 표기하지 않으며, 모집단이 가구이면 개인 통계처럼 설명하지 않는다.

이 문서는 `korea-avg` 서비스의 기준점을 공식 1차 자료와 대조한 결과다. 결론적으로 기존 문서의 순자산·연봉·소비 기준은 모집단 또는 평균/중앙값 정의가 섞여 있었고, 연애 횟수·이상형 희소성·분포 모수에는 국가통계로 확인할 수 없는 값이 포함돼 있었다. 따라서 아래처럼 **공식 관측값**, **서비스용 추정값**, **근거 없음**을 분리한다.

## 1. 검증 결과 요약

| 주제 | 판정 | 수정한 공식 기준 | 서비스에서의 해석 |
| :--- | :--- | :--- | :--- |
| 순자산 | 기존 연령별 값 오류 | 2025년 3월 말, 가구주 연령별 **가구 순자산 중앙값** | 개인 자산이 아니라 해당 연령 가구주가 이끄는 가구 기준 |
| 연봉·소득 | 평균을 중앙값으로 잘못 표기 | 2024년 12월 임금근로일자리의 연령별 **월평균 보수** | 연간 환산값은 월평균×12인 단순 환산치이며 실제 연봉 중앙값이 아님 |
| 신장·체중 | 평균값은 확인, 기간 표기 오류 | 국민건강보험공단 2024년 건강검진 평균 | 건강검진 수검자 평균이며 전 국민 모수 평균은 아님 |
| 소비 | 개인·연령별 값으로 볼 근거 없음 | 2025년 전국 1인 이상 **가구** 월평균 소비지출 293.9만 원 | 개인의 나이별 소비 백분위로 사용할 수 없음 |
| 연애 횟수 | 국가통계 근거 없음 | 민간 조사 참고값만 존재 | 오락성 자체 모델로만 표시해야 함 |
| 이상형 희소성 | 결합확률 근거 없음 | 조건별 공식 통계는 일부 존재하나 결합분포는 없음 | 독립성·상관 보정 등을 둔 자체 시뮬레이션 |

## 2. 공식 관측값과 교정 기준

### 2.1 순자산 (`net_worth`)

출처는 국가데이터처·한국은행·금융감독원의 [2025년 가계금융복지조사 결과](https://mods.go.kr/board.es?act=view&bid=215&list_no=439535&mainXml=Y&mid=b80501010000) 및 [부록 통계표 XLSX](https://mods.go.kr/boardDownload.es?bid=215&list_no=439535&seq=8)이다. 기준 시점은 2025년 3월 말이고 단위는 만 원이다.

| 가구주 연령 | 평균 순자산 | 중앙값 | 서비스 기준점 |
| :--- | ---: | ---: | ---: |
| 29세 이하 | 10,796 | 5,000 | 5,000 |
| 30~39세 | 25,060 | 15,585 | 15,585 |
| 40~49세 | 48,389 | 28,384 | 28,384 |
| 50~59세 | 55,161 | 31,685 | 31,685 |
| 60세 이상 | 53,591 | 25,000 | 25,000 |

- 기존 기준점 `3,500 / 12,000 / 21,000 / 27,000 / 22,000만 원`은 최신 공식 중앙값과 일치하지 않아 위 값으로 교정한다.
- 공식 표는 **가구주 연령별 가구 순자산**이다. 사용자가 입력하는 개인 순자산과 동일한 모집단이 아니므로 결과 화면에도 `가구 기준`임을 밝혀야 한다.
- 연령과 성별을 교차한 중앙값은 공표표에 없다. 기존 `남성 +300/+1,000/+2,000`, `여성 -300/-1,000/-2,000만 원` 보정은 삭제 대상이다.
- 10대의 독립적인 가구 순자산 기준은 없다. 10대 결과에는 백분위를 제공하지 않거나 `29세 이하 가구 참고값`임을 표시해야 한다.

### 2.2 임금·소득 (`income_salary`)

출처는 국가데이터처의 [2024년 임금근로일자리 소득(보수) 결과 PDF](https://sri.kostat.go.kr/boardDownload.es?bid=11113&list_no=443648&seq=1)다. 작성 대상은 **2024년 12월 임금근로일자리에서 하루 이상 일한 근로자**이며, 복수 일자리를 가진 한 사람은 일자리별로 포착될 수 있다. 단위는 월 만 원이다.

| 연령 | 전체 월평균 | 연 환산(×12) | 남성 월평균 | 여성 월평균 |
| :--- | ---: | ---: | ---: | ---: |
| 19세 이하 | 95 | 1,140 | 103 | 88 |
| 20대 | 271 | 3,252 | 286 | 255 |
| 30대 | 397 | 4,764 | 428 | 354 |
| 40대 | 469 | 5,628 | 544 | 363 |
| 50대 | 445 | 5,340 | 548 | 306 |
| 60대 | 293 | 3,516 | 362 | 200 |
| 70세 이상 | 165 | 1,980 | 234 | 95 |

- 전체 연령의 월 중위소득은 288만 원이지만 공식 자료는 연령별 중위소득을 직접 제시하지 않는다.
- 기존 `3,300 / 4,800 / 5,800 / 6,200 / 4,000만 원`은 대체로 평균에 가까운 값인데도 `중앙값`이라고 적혀 있었다. 기준명은 **연령별 월평균 보수의 연 환산값**으로 교정한다.
- 성별·연령별 평균이 직접 공표되므로 임의의 정액 성별 보정을 적용하지 않는다. 성별을 사용할 때는 위 월평균에 12를 곱한 값을 직접 사용한다.
- 월평균 보수를 로그정규분포의 중앙값으로 넣어 계산한 `상위 %`는 공식 백분위가 아니다. 공식 소득구간 분포 또는 마이크로데이터로 별도 보정하기 전까지는 `모델 추정치`로 표시한다.

### 2.3 신장·체중 (`physical_condition`)

출처는 KOSIS 국민건강보험공단 건강검진통계의 `시도별 연령별 성별 평균 신장 분포 현황: 일반`([통계표 DT_35007_N130](https://stat.kosis.kr/nsieu/view/tree.do?hOrg=350&id=350_350_35007_007%2AMT_OTITLE&task=branchView)) 및 동일 계열의 평균 체중 표다. 현재 코드에 적재된 기준연도는 2024년이다.

| 구분 | 30대 남성 | 30대 여성 |
| :--- | ---: | ---: |
| 전국 평균 신장 | 174.55cm | 161.91cm |
| 전국 평균 체중 | 79.76kg | 60.19kg |
| 서울 평균 신장 | 175.22cm | 162.41cm |
| 서울 평균 체중 | 79.33kg | 59.17kg |

- 기존 문서의 `2024~2026` 표기는 잘못이며 **2024년**으로 고친다.
- 이 값은 국가건강검진 수검자의 산술평균이다. 중앙값 또는 모든 국민의 전수 평균으로 설명하면 안 된다.
- 건강보험공단 공표표에서 현재 모델의 고정 표준편차 `신장 남 5.8/여 5.3cm`, `체중 남 10.5/여 8.8kg`를 확인할 수 없다. 이 값들은 **서비스 분포 가정**으로만 유지하며 공식 수치라고 표기하지 않는다.

### 2.4 소비 (`spending_style`)

출처는 통계청의 **가계동향조사 (2022년) [1인 가구의 연령별 월평균 소비지출]** 데이터이다.

| 연령대 | 1인 가구 월평균 소비지출 총합 | 주요 항목 지출 (단위: 천 원) |
| :--- | ---: | :--- |
| **39세 이하** | **155.1만 원** (1,551천 원) | 음식·숙박 398, 주거·수도·광열 290, 교통 211, 오락·문화 165 |
| **40~49세** | **179.9만 원** (1,799천 원) | 음식·숙박 342, 주거·수도·광열 287, 식료품·비주류 254, 교통 247 |
| **50~59세** | **166.8만 원** (1,668천 원) | 주거·수도·광열 290, 음식·숙박 259, 교통 236, 식료품·비주류 216 |
| **60세 이상** | **94.8만 원** (948천 원) | 주거·수도·광열 240, 보건 166, 식료품·비주류 192, 음식·숙박 123 |

- 1인 가구 기준 연령별 소비지출 합계: **39세 이하 155만 원 / 40대 180만 원 / 50대 167만 원 / 60세 이상 95만 원**
- 이전의 막연한 전체 가구 평균에서 탈피하여, 1인 가구 사용자의 실제 생활 지출 감각과 정확하게 부합하는 2022년 통계청 실측치로 교정한다.
- 10대~30대는 `39세 이하` 관측값(155만 원)을 기준점으로 사용한다.

### 2.5 연애 횟수 (`dating_count`)

- 통계청·한국보건사회연구원의 국가승인통계에서 전 연령의 누적 연애 횟수 중앙값을 확인하지 못했다.
- 참고 가능한 민간 자료인 대학내일20대연구소의 [밀레니얼·Z세대 연애와 결혼 실태조사](https://www.20slab.org/Archives/32815)는 만 15~34세 미혼 남녀 500명을 조사해 연애 경험자의 평균 연애 횟수 4.7회, 30~34세 평균 5.5회, 15~18세 평균 5.2회를 제시한다. 공개된 본문에는 성별×연령 교차표가 없다.
- 서비스에서는 사용자의 요청에 따라 아래 값을 적용한다. 조사에서 직접 확인되는 숫자와 서비스 추론값을 혼동하지 않도록 결과 화면에 `민간 조사 + 자체 추론`이라고 표시한다.

| 연령대 | 여성 평균 기준 | 남성 평균 기준 | 값의 지위 |
| :--- | ---: | ---: | :--- |
| 10대 | 5.0회 | 5.4회 | 15~18세 전체 평균 5.2회에 성별 ±0.2회 추론 |
| 20대 | 4.0회 | 4.4회 | 전체 평균 4.7회를 참고해 서비스용으로 추론 |
| 30대 | 5.3회 | 5.7회 | 30~34세 전체 평균 5.5회에 성별 ±0.2회 추론 |
| 40대 | 6.0회 | 6.4회 | 30대보다 높도록 자체 추론 |
| 50대 | 6.6회 | 7.0회 | 40대보다 높도록 자체 추론 |
| 60대 이상 | 7.0회 | 7.4회 | 50대보다 높도록 자체 추론 |

- 위 성별 차이와 20대·40대 이상 값은 국가통계나 조사 원자료에서 관측된 수치가 아니다. 연령이 높을수록 누적 횟수가 늘어난다는 단순 가정으로 만든 **오락성 자체 모델 기준점**이다.

### 2.6 이상형 희소성 (`ideal_match`)

- 키, 임금, 흡연 여부 등의 주변분포는 각각 공식 통계로 구할 수 있지만, 이를 모두 교차한 결합분포는 공표되지 않는다.
- 기존 직업군 비율 `15%/13%`, 체형 비율 `22%/35%`, 결합확률 댐핑 지수 `0.88`, 점수 중앙값 `55~60`, `85점 이상 상위 15%`는 공식 근거가 확인되지 않는다.
- 조건을 서로 독립으로 곱하면 키·소득·직업·흡연·체형 사이의 상관을 무시해 희소성을 과장할 수 있다. 이 결과는 `대한민국 상위 %`가 아니라 **입력 조건 기반 오락성 희소도 점수**로 표기한다.

## 3. 서비스 계산 모수의 지위

현재 서비스는 양수형 지표에 로그정규분포를 가정한다.

$$z = \frac{\ln(x)-\ln(m)}{\sigma}, \qquad P(X \le x)=\Phi(z)$$

여기서 `m`은 모델 기준점, `σ`는 로그 스케일의 분산 모수다. Abramowitz & Stegun 7.1.26 근사식으로 표준정규 CDF를 계산하고 0.5~99.5%로 제한한다.

| 모수 | 기존값 | 검증 결과 |
| :--- | ---: | :--- |
| 순자산 로그 시그마 | 0.9 | 공식 공표값 아님. 서비스용 가정 |
| 임금 로그 시그마 | 0.45 | 공식 공표값 아님. 연령별 소득구간으로 재적합 필요 |
| 소비 로그 시그마 | 0.5 | 공식 공표값 아님. 개인 원자료로 재적합 필요 |
| 연애 로그 시그마 | 0.6 | 공식 공표값 아님. 오락성 가정 |
| 신장 표준편차 | 남 5.8cm / 여 5.3cm | NHIS 평균표에서 확인되지 않은 모델 가정 |
| 체중 표준편차 | 남 10.5kg / 여 8.8kg | NHIS 평균표에서 확인되지 않은 모델 가정 |

따라서 현재 산출되는 백분위는 국가기관이 공표한 백분위가 아니라, 공식 평균 또는 중앙값 일부에 자체 분포를 결합한 **모델 추정치**다. 결과 화면과 공유 문구에서 `정확한 위치`, `공식 상위 %` 같은 표현은 피해야 한다.

또한 순자산은 0 또는 음수일 수 있어 단일 로그정규분포로 전체 가구를 표현할 수 없다. 현재 `floor=100만 원` 처리는 100만 원 이하의 서로 다른 값을 같은 위치로 뭉개므로, 음수·0 구간을 포함한 경험적 분포를 확보하기 전까지 극단 구간의 순위 정확도를 보장할 수 없다.

## 4. 적용 우선순위

1. 순자산 기준점을 2025년 가구 순자산 중앙값으로 교체하고 성별 보정을 제거한다.
2. 임금 기준을 2024년 12월 월평균 보수로 명칭 변경하고 성별·연령별 직접 공표값을 사용한다.
3. 신체 데이터 기준연도를 2024년으로 고정하고 표준편차를 자체 가정으로 표시한다.
4. 소비·연애·이상형 결과에는 `오락성 자체 모델` 표시를 붙이며, 검증 가능한 원자료를 확보하기 전에는 국가통계 백분위로 홍보하지 않는다.
