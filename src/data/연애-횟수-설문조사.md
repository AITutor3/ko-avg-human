# 연애 횟수 설문조사 결과 이미지

## 카드용 공통 제작 기준

- 1:1, 1024×1024 PNG, 반드시 완전한 흰색(`#FFFFFF`) 배경
- 굵고 살짝 불규칙한 검정 외곽선, 손그림 한국 웹툰 낙서풍
- 둥근 머리와 짧은 팔다리의 친근한 전신 인물 캐릭터, 결과마다 다른 포즈와 복장
- 흑백·회색 중심에 결과별 포인트색 1개만 사용
- 캐릭터와 핵심 소품을 중앙 75% 안에 배치하고 카드 문구용 흰 여백 확보
- 글자, 숫자, 말풍선, 로고, 워터마크, 그림자, 바닥선, 복잡한 배경, 3D 렌더링 금지

## 불타는 사랑꾼 만렙 — 불타는 사랑꾼

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 검정 라이더 재킷을 입은 인물이 커다란 하트 모양 화살을 어깨에 메고 앞으로 성큼 걸어간다. 머리카락 끝은 작고 둥근 불꽃처럼 위로 솟고, 볼에는 옅은 홍조, 눈은 반짝이지만 표정은 태연한 열정적인 사랑꾼. 굵고 삐뚤한 검정 외곽선, 빠르게 그린 듯한 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 짙은 회색 중심, 오직 하트 화살과 머리의 작은 불꽃에만 선명한 레드 포인트. 중앙 75% 안의 역동적인 전신 실루엣, 넉넉한 흰 여백. 실제 화염 배경, 연기, 그림자, 바닥선, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 공격적 표현과 3D 금지.
```

