# 결혼시장 희소성 설문조사 결과 이미지

## 카드용 공통 제작 기준

- 1:1, 1024×1024 PNG, 반드시 완전한 흰색(`#FFFFFF`) 배경
- 굵고 살짝 불규칙한 검정 외곽선, 손으로 그린 듯한 한국 웹툰 낙서풍
- 둥근 머리와 짧은 팔다리, 무심하지만 호감 가는 표정의 전신 인물 캐릭터
- 흑백·회색 중심에 결과별 포인트색 1개만 사용
- 전신과 핵심 상징을 중앙 75% 안에 배치하고 카드 문구용 흰 여백 확보
- 글자, 숫자, 말풍선, 로고, 워터마크, 그림자, 바닥선, 패턴, 그라데이션, 3D 렌더링 금지

## 육각형 완벽 인재 — 육각형 챔피언

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 단정한 검정 재킷과 흰 셔츠를 입은 인물이 육각형 모양의 작은 방패를 가슴 앞에 들고 반듯하게 서 있다. 방패 가운데에는 글자 없이 서로 겹친 두 개의 단순한 반지 선 아이콘만 있다. 머리에는 아주 작은 왕관이 살짝 기울어져 있고, 모든 조건을 갖췄지만 과시하지 않는 담담한 반미소. 굵고 삐뚤한 검정 외곽선, 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 차콜 중심, 오직 왕관과 방패 테두리에만 절제된 보라색 포인트. 중앙 75% 안의 대칭적인 전신 실루엣과 넉넉한 흰 여백. 후광, 배경 장식, 그림자, 바닥선, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 3D 금지.
```

## 친근한 매력 인재 — 볼매 유망주

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 포근한 회색 니트 조끼와 셔츠를 입은 인물이 작은 반지 상자를 두 손으로 조심스럽게 내민다. 한쪽 신발 끈이 살짝 풀려 있고 머리카락도 조금 헝클어져 있어 완벽하진 않지만 정이 가는 모습. 눈은 순하게 휘고 볼은 살짝 붉어진 수줍고 믿음직한 미소, 몸을 조금 앞으로 숙인 자세. 굵고 살짝 불규칙한 검정 외곽선, 담백한 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 연회색 중심, 오직 반지 상자와 볼 홍조에만 따뜻한 살구색 포인트. 중앙 75% 안의 포근한 전신 실루엣, 카드 문구용 넉넉한 흰 여백. 별 반짝임, 배경 장식, 그림자, 바닥선, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 3D 금지.
```
