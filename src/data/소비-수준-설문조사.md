# 소비 수준 설문조사 결과 이미지

## 카드용 공통 제작 기준

- 1:1, 1024×1024 PNG, 반드시 완전한 흰색(`#FFFFFF`) 배경
- 참고 이미지의 굵고 살짝 불규칙한 검정 외곽선과 손그림 한국 웹툰 낙서풍을 반영하되 복제하지 않음
- 둥근 머리와 짧은 팔다리, 무심하면서 유머러스한 표정의 전신 인물 캐릭터
- 흑백·회색 중심에 결과별 포인트색 1개만 사용
- 캐릭터와 핵심 소품을 중앙 75% 안에 배치하고 외곽에는 카드 문구용 흰 여백 확보
- 글자, 숫자, 말풍선, 로고, 워터마크, 그림자, 바닥선, 복잡한 배경, 3D 렌더링 금지

## 플렉스 과소비 마왕 — 플렉스 과소비형

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 오버사이즈 검정 재킷과 작은 선글라스를 쓴 인물이 양손 가득 쇼핑백을 들고 과장되게 어깨를 편다. 재킷 주머니에서는 결제 카드 한 장이 비스듬히 보이고, 쇼핑백 하나는 손가락 끝에 위태롭게 걸려 있다. 신나지만 살짝 허세가 느껴지는 능청스러운 표정. 굵고 삐뚤한 검정 외곽선, 거친 펜선의 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 차콜 중심, 오직 선글라스와 쇼핑백 손잡이에만 핫핑크 포인트. 중앙 75% 안의 강한 전신 실루엣과 넉넉한 흰 여백. 배경 소품, 날리는 지폐, 그림자, 바닥선, 글자, 숫자, 말풍선, 브랜드 로고, 워터마크 없음. 3D 금지.
```

## 경험 라이프 소비러 — 경험소비형

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 버킷햇과 편한 바람막이를 입은 인물이 목에 작은 카메라를 걸고 한 손에는 테이크아웃 음료, 다른 손에는 접힌 종이 지도를 든 채 한 발 앞으로 내딛는다. 눈이 반달처럼 휘어진 만족스러운 미소, 여행지로 막 출발하는 가벼운 자세. 굵고 살짝 불규칙한 검정 외곽선, 손그림 한국 웹툰 낙서풍, 둥근 머리와 짧은 팔다리, 흑백과 연회색 중심, 오직 모자와 카메라 스트랩에만 산뜻한 코랄 오렌지 포인트. 중앙 75% 안에 간결한 전신, 카드 문구용 흰 여백. 풍경 배경, 그림자, 바닥선, 글자, 숫자, 말풍선, 브랜드 로고, 워터마크 없음. 3D 금지.
```

## 알뜰 자산 저축가 — 저축 수호형

```text
Use case: illustration-story. 한국 모바일 설문 결과 카드용 정사각형 이미지. 완전한 흰색(#FFFFFF) 배경 한가운데, 단정한 회색 니트와 동그란 안경을 쓴 인물이 동전 저금통을 방패처럼 가슴 앞에 품고 작은 계산기를 빠르게 두드린다. 허리에는 짧은 망토가 달려 있어 생활비를 지키는 소박한 수호자처럼 보인다. 입술을 꾹 다문 뿌듯하고 야무진 표정, 다리를 안정적으로 벌린 자세. 굵고 삐뚤한 검정 외곽선, 한국 웹툰 낙서풍, 둥글고 짧은 전신 비율, 흑백과 회색 중심, 오직 망토와 계산기 버튼에만 딥그린 포인트. 중앙 75% 배치, 넉넉한 흰 여백. 배경 요소, 그림자, 바닥선, 글자, 숫자, 말풍선, 로고, 워터마크 없음. 3D 금지.
```
